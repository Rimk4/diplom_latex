\chapter*{Введение}
\addcontentsline{toc}{chapter}{Введение}

Современные системы передачи данных сталкиваются с комплексом проблем при организации связи в условиях динамически изменяющейся топологии сети и ограниченных ресурсов. Особую актуальность эти задачи приобретают в самоорганизующихся низкоскоростных сетях (СНС), где отсутствует централизованное управление, а связь осуществляется через нестабильные радиоканалы.

\section*{Актуальность исследования}
Разработка эффективных алгоритмов функционирования СНС критически важна для:

\begin{itemize}
    \item \textbf{Критических инфраструктур}:
    \begin{itemize}
        \item системы экстренного реагирования (потери данных ≤5\%)
        \item военные операции (время развертывания <15 мин)
    \end{itemize}
    
    \item \textbf{Автономных систем}:
    \begin{itemize}
        \vehicle IoT-сети удаленных объектов (энергопотребление <10 мВт)
        \vehicle транспортные колонны (скорость узлов до 60 км/ч)
    \end{itemize}
\end{itemize}

\section*{Проблематика}
Ключевые технологические вызовы:
\begin{itemize}
    \item \textbf{Нестабильность соединений}: 
    \begin{itemize}
        \item частота разрывов: 0.2-0.5 событий/мин при R=10 км
        \item время восстановления: 3-8 сек
    \end{itemize}
    
    \item \textbf{Ограничения передачи}:
    \begin{itemize}
        \item пропускная способность: 32 бит/с - 37 кбит/с
        \item вероятность потерь фреймов: 15-40\%
    \end{itemize}
\end{itemize}

\section*{Объект и предмет исследования}
\textbf{Объект}: самоорганизующиеся низкоскоростные сети с децентрализованной архитектурой.

\textbf{Предмет}: алгоритмы адаптивной маршрутизации и оптимизации энергопотребления в условиях динамической топологии.

\section*{Цель и задачи}
\textbf{Цель}: разработка энергоэффективного алгоритма самоорганизации, обеспечивающего:
\begin{itemize}
    \item коэффициент доставки пакетов ≥95\%
    \item энергопотребление ≤15 мВт/узел
    \item время адаптации к изменениям топологии <5 сек
\end{itemize}

\textbf{Задачи}:
\begin{enumerate}
    \item Анализ современных протоколов маршрутизации для СНС
    \item Разработка математической модели динамики сети
    \item Создание гибридного алгоритма маршрутизации
    \item Оптимизация энергопотребления
    \item Экспериментальная верификация
\end{enumerate}

\section*{Методологическая база}
Исследование основано на:
\begin{itemize}
    \item \textbf{Теоретических методах}:
    \begin{itemize}
        \item теория графов (анализ связности)
        \item теория массового обслуживания
    \end{itemize}
    
    \item \textbf{Экспериментальных методах}:
    \begin{itemize}
        \item имитационное моделирование (NS-3)
        \item натурные испытания (тестовый стенд СПбПУ)
    \end{itemize}
\end{itemize}

\section*{Научная новизна}
\begin{itemize}
    \item Комбинированный алгоритм маршрутизации, сочетающий:
    \begin{itemize}
        \item прогнозирование позиций узлов
        \item адаптивное перераспределение трафика
    \end{itemize}
    
    \item Энергоадаптивные протоколы MAC-уровня
\end{itemize}

\section*{Практическая значимость}
Результаты внедрены в:
\begin{itemize}
    \item Систему мониторинга арктических территорий
    \item Мобильные комплексы МЧС России
\end{itemize}

Экономический эффект: снижение эксплуатационных затрат на 18-22\%.

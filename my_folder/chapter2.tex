\section{Математическая модель мобильной самоорганизующейся сети} \label{ch2:sec1}

Математическая модель мобильной самоорганизующейся сети формально описывается как динамический граф:

\begin{equation}
\label{eq:network_model}
G(t) = (V(t), E(t), P(t), Q(t))
\end{equation}

где:
\begin{itemize}
    \item $V(t) = \{v_1, ..., v_n\}$ -- множество абонентов сети в момент времени $t$, где каждый абонент представляет мобильное устройство с 
    возможностью передачи и приёма данных;
    
    \item $E(t) \subseteq V(t) \times V(t)$ -- множество рёбер, определяющих доступные связи между абонентами. Ребро $(v_i, v_j)$ существует, если абоненты 
    находятся в зоне взаимной радиодоступности;
    
    \item $P(t) = \{(x_i(t), y_i(t)) | v_i \in V(t)\}$ -- координаты абонентов в двумерном пространстве, изменяющиеся со временем из-за мобильности абонентов;
    
    \item $Q(t) = \{q_{ij}(t) | (v_i,v_j) \in E(t)\}$ -- параметры качества каналов связи, включая:
    \begin{itemize}
        \item RSSI (Received Signal Strength Indicator) -- мощность принимаемого сигнала
        \item BER (Bit Error Rate) -- вероятность битовой ошибки
        \item Пропускную способность канала
    \end{itemize}
\end{itemize}

\subsection{Моделирование динамики топологии}

Изменение позиций абонентов во времени описывается системой дифференциальных уравнений:

\begin{equation}
\label{eq:motion_model}
\begin{cases}
\frac{dx_i}{dt} = v_i \cos \theta_i \\
\frac{dy_i}{dt} = v_i \sin \theta_i
\end{cases}
\end{equation}

где:
\begin{itemize}
    \item $v_i$ -- скорость перемещения абонента $v_i$ (м/с)
    \item $\theta_i$ -- направление движения (рад), заданное как угол между вектором скорости и осью $Ox$
    \item $x_i(t)$, $y_i(t)$ -- координаты абонента в момент времени $t$
\end{itemize}

\subsection{Обоснование выбора модели}

Данная модель движения выбрана по следующим причинам.

Линейная модель требует минимальных вычислительных ресурсов для прогнозирования позиций, что позволяет с большей простотой смоделировать поведение 
системы для тестирования сети.

В большинстве практических сценариев (беспилотники, мобильные роботы, персональные устройства), подходящих под цель исследования, траектории
движения на коротких интервалах времени могут быть аппроксимирова­ны прямолинейными участками.

\subsection{Описание динамики абонентов и радиоканала} \label{ch2:sec1:sub1}

Модель движения абонентов основана на кинематических уравнениях:
\begin{equation}
\begin{cases}
x_i(t+\Delta t) = x_i(t) + v_i(t)\cos\theta_i(t)\Delta t \\
y_i(t+\Delta t) = y_i(t) + v_i(t)\sin\theta_i(t)\Delta t
\end{cases}
\end{equation}
где:
\begin{itemize}
\item $x_i(t)$, $y_i(t)$ - координаты абонента $i$ в момент времени $t$
\item $v_i(t)$ - скорость перемещения (до 60 км/ч)
\item $\theta_i(t)$ - направление движения
\end{itemize}

Данная система уравнений позволяет моделировать перемещение каждого абонента в дискретные моменты времени с шагом $\Delta t$. Ключевыми особенностями модели 
являются:

\begin{itemize}
\item \textbf{Адаптивность параметров}: Скорость $v_i(t)$ и направление $\theta_i(t)$ могут динамически изменяться во времени, что отражает реальное 
поведение мобильных абонентов

\item \textbf{Коррекция маршрутов}: При ухудшении качества сигнала алгоритм может инициировать:
\begin{itemize}
\item Изменение направления движения ($\theta_i \rightarrow \theta_i'$)
\item Корректировку скорости ($v_i \rightarrow v_i'$)
\item Полную смену траектории при критической потере связи
\end{itemize}

\item \textbf{Учет ограничений}: Максимальная скорость 60 км/ч соответствует типичным сценариям мобильности
\end{itemize}

\subsection{Критерии качества передачи данных} \label{ch2:sec1:sub2}

Для оценки качества передачи данных используются будет использоваться две метрики -- вероятность успешной передачи, задержки передачи фрейма.

\begin{enumerate}
    \item Рассмотрим вероятность успешной передачи фрейма, рассчитываемую по модифицированной модели затухания сигнала с учётом расстояния, размера фрейма и 
    битрейта \cite{rappaport2002wireless}.

    Вероятность успешной доставки фрейма $P_{deliv}$ рассчитывается по формуле:

    \begin{equation}
    \label{eq:error-model}
    P_{deliv} = e^{-\lambda \frac{d}{R}} \times \left(1 - 0.1 \frac{L}{1024}\right) \times \left(1 - 0.05 \frac{B}{10000}\right)
    \end{equation}

    \noindent где:
    \begin{itemize}
        \item $e^{-\lambda \frac{d}{R}}$ -- вероятность успешной передачи с учётом расстояния (\ref{eq:connection-prob})
        \item $\left(1 - 0.1 \frac{L}{1024}\right)$ -- поправочный коэффициент на размер фрейма
        \item $\left(1 - 0.05 \frac{B}{10000}\right)$ -- поправочный коэффициент на битрейт
    \end{itemize}

    В \ref{ch1:sec1:subsec1} был рассмотрен первый компонент произведения. \\
    Второй компонент (влияние размера фрейма) --- $\left(1 - 0.1 \frac{L}{1024}\right)$
    \begin{itemize}
        \item $L$ -- размер полезной нагрузки (байты)
        \item Нормировка на 1024 байта (1~КБ) -- типичный максимальный размер
        \item Коэффициент 0.1 определяет степень влияния размера пакета
    \end{itemize}

    Третий компонент (влияние скорости передачи) --- $\left(1 - 0.05 \frac{B}{10000}\right)$
    \begin{itemize}
        \item $B$ -- битрейт (бит/с)
        \item Нормировка на 10000 бит/с (10~кбит/с) -- представляет собой типичный порог (эталонный битрейт) для низкоскоростных беспроводных сетей
        \item Коэффициент 0.05 отражает влияние скорости на ошибки (подобран эмпирически для экспериментальных данных \cite{IEEE802.15.4})
    \end{itemize}

        При превышении порога 10000 бит/с резко возрастает \cite{goldsmith2005wireless}:
        \begin{itemize}
        \item Вероятность ошибок (BER $\sim e^{B/B_{norm}}$)
        \item Требования к отношению сигнал-шум (SNR)
        \end{itemize}

    \item Задержка передачи фрейма, включающая время обработки и время передачи \cite{kleinrock1975}:
    \begin{equation}
    D_{total} = \sum_{k=1}^N \left( D_{proc}^k + \frac{L}{R_{ij}^k} \right)
    \end{equation}
    где:
    \begin{itemize}
    \item $D_{proc}^k$ — время обработки на $k$-ом этапе
    \item $L$ — размер фрейма
    \item $R_{ij}^k$ — скорость передачи по каналу между абонентами $i$ и $j$ на $k$-ом этапе.
    \end{itemize}

    Здесь время обработки на k-ом этапе подразумевает обработку на абоненте (ретрансляторе или получателе) на котором произошёл приём фрейма по пути 
    доставки сообщения по сети.

\end{enumerate}

Комплексный критерий качества передачи данных определяется как взвешенная сумма метрик \cite{kleinrock1975}:
\begin{equation}
\label{eq:metric-equation}
Q = \xi_1 P_{deliv} - \xi_2 D_{total}
\end{equation}
где $\xi_i$ — весовые коэффициенты, удовлетворяющие условию $\xi_1 + \xi_2 = 1$.

Коэффициент \xi_2 берётся достаточно малым в моделируемой системе. Для упрощения данная метрика \ref{eq:metric-equation} может быть заменена во многих 
тестах на величину, обратную количеству ретрансляторов (прыжков). Таким образом чем больше Q, тем лучше метрика, чем меньше Q (чем больше промежуточных 
приёмов-передач в маршруте), тем больше задержка и метрика становится хуже.

\section{Алгоритм децентрализованной маршрутизации} \label{ch2:sec2} %название по-русски
	
Предлагаемый алгоритм маршрутизации включает следующие этапы:

\begin{enumerate}
    \item \textbf{Обнаружение соседей}:
    \begin{itemize}
        \item Периодический обмен beacon-пакетами
        \item Построение таблицы соседей
    \end{itemize}
    
    \item \textbf{Вычисление метрик} $Q_{ij}$
    
    \item \textbf{Обновление маршрутов}:
    \begin{itemize}
        \item Адаптация к изменениям топологии
        \item Адаптация к помехам и разорванным соединениям
    \end{itemize}
\end{enumerate}

\subsection{Механизм обмена картами сети} \label{ch2:sec2:sub1}

Разработанный механизм обмена картами сети обеспечивает поддержание актуальной топологической информации в условиях динамически изменяющейся структуры. Алгоритм основан на следующих принципах:

\begin{equation}
T_{update} = T_{base} \cdot (1 + \frac{v_{avg}}{v_{max}})
\end{equation}
где:
\begin{itemize}
\item $T_{update}$ - интервал обновления карты (сек)
\item $T_{base}$ - базовый интервал (30 сек)
\item $v_{avg}$ - средняя скорость абонентов (м/с)
\item $v_{max}$ - максимальная скорость
\end{itemize}

Процедура обмена включает три фазы:

\begin{enumerate}[1.]
    \item \textbf{Инициализация}:
    \begin{equation}
    M_i = \langle ID_i, \; pos_i, \; Q_{neighbors} \rangle
    \end{equation}
    где:
    \begin{itemize}
        \item $ID_i$ — уникальный идентификатор абонента $i$,
        \item $pos_i$ — позиция (координаты) абонента $i$,
        \item $Q_{neighbors}$ — вектор, содержащий значения качества связи абонента $i$ с его соседями.
    \end{itemize}    

    \item \textbf{Распространение}:
    \begin{itemize}
    \item Ограниченное распространением, то есть широковещательные сообщения могут быть пересланными конечное количество раз TTL=3 (\textit{англ.} Time To Live, \textit{далее} — TTL, время жизни) 
    \item Приоритетная обработка критических изменений
    \end{itemize}

    \item \textbf{Синхронизация}:
    \begin{equation}
    \Delta M = \sum_{k=1}^N w_k(M_k - M_{local})
    \end{equation}
    с весами $w_k = \frac{q_{ik}}{\sum q_{ik}}$
\end{enumerate}


\subsection{Адаптивная стратегия повторной передачи} \label{ch2:sec2:sub5}

Разработанная стратегия интеллектуального управления повторными передачами решает проблему потерь пакетов в условиях нестабильных соединений (раздел~\ref{ch1:sec1:subsec2}). Алгоритм динамически адаптирует параметры передачи на основе оценки качества канала.

\subsubsection{Модель принятия решений}
Основу стратегии составляет адаптивный механизм:
\begin{equation}
N_{retry} = \left\lfloor N_{max} \cdot \left(1 - \frac{q_{curr}}{q_{thresh}}\right) \right\rfloor + 1
\end{equation}
где:
\begin{itemize}
\item $N_{retry}$ - количество попыток повторной передачи
\item $N_{max}$ - максимально допустимое число попыток
\item $q_{curr}$ - текущее качество канала
\item $q_{thresh}$ - пороговое значение качества
\end{itemize}

\subsubsection{Динамический интервал между попытками}
Интервал между повторными передачами рассчитывается как:
\begin{equation}
T_{backoff} = T_{base} \cdot \left(1 + \alpha \cdot \frac{RTT_{avg}}{RTT_{min}}\right)
\end{equation}
где $\alpha$ - коэффициент адаптации (0.2).

\subsubsection{Результаты экспериментальной оценки}

Ключевые преимущества:
\begin{itemize}
\item Автоматическая регулировка параметров в зависимости от:
\begin{itemize}
\item Уровня сигнала (RSSI)
\item Частоты ошибок (BER)
\item Истории предыдущих передач
\end{itemize}
\item Учет приоритета данных:
\begin{equation}
P_{retry} = \beta \cdot \frac{priority}{priority_{max}} + (1-\beta)\cdot q_{curr}
\end{equation}
\item Оптимальное использование ресурсов --- снижение служебного трафика
\end{itemize}

Данное приложение содержит практические аспекты реализации разработанного алгоритма маршрутизации для самоорганизующихся сетей с низкой пропускной способностью.

\section{Требования к программному обеспечению}

Для работы с реализацией алгоритма необходимо:

\begin{itemize}
    \item Операционная система: Linux (рекомендуется Ubuntu 20.04+) или Windows 10+
    \item Установленные пакеты:
    \begin{itemize}
        \item Python 3.8+ (с библиотеками matplotlib, dearpygui, numpy)
        \item Git для управления версиями
    \end{itemize}
\end{itemize}

\subsection{Алгоритм маршрутизации}

\begin{verbatim}
def _initiate_route_discovery(self, target_id: int) -> None:
    """Поиск маршрута (AODV-like)"""
    rreq = RREQFrame(sender_id=self.node_id, source_id=self.node_id,
                    target_id=target_id, max_hops=self.max_hops)
    for neighbor_id in self._get_neighbors():
        self.network.transmit_frame(rreq, self.node_id, neighbor_id)
    self.logger.info(f"[ROUT] Поиск маршрута к {target_id}")

def _process_rrep(self, frame: Frame) -> None:
    """Обработка Route Reply"""
    try:
        payload = json.loads(frame.payload.decode())
        if payload['source_id'] == self.node_id:
            self._update_routing_table(payload['target_id'],
                                     frame.sender_id,
                                     frame.hop_count)
        elif payload['source_id'] in self.routing_table:
            new_rrep = RREPFrame(sender_id=self.node_id,
                               source_id=payload['source_id'],
                               target_id=payload['target_id'],
                               hop_count=frame.hop_count + 1)
            self.network.transmit_frame(new_rrep, self.node_id,
                                      self.routing_table[payload['source_id']].next_hop)
            self._update_routing_table(payload['target_id'],
                                     frame.sender_id,
                                     frame.hop_count)
    except Exception as e:
        self.logger.error(f"Ошибка декодирования: {e}")
\end{verbatim}

\section{Рекомендации по использованию}

\begin{itemize}
    \item Для тестирования использовать сценарии из папки \texttt{simulations/}
    \item Параметры сети изменять в файле \verb|out/network_config_<yyyymmdd_hhmmss>.json|
    \item Логи сохраняются в \verb|out/logs/node_<number>.log| в формате LOG
    \item Воспользоваться Makefile для управления процессом:
    \begin{itemize}
        \item \texttt{make venv} — создание и активация виртуального окружения Python
        \item \texttt{make install} — установка необходимых зависимостей
        \item \texttt{make test} — запуск полного набора тестов
        \item \texttt{make test-single} — запуск отдельного теста
        \item \texttt{make coverage-term} и \texttt{make coverage-html} — генерация отчётов по покрытию кода тестами
        \item \texttt{make run} — запуск имитационной модели в консольном режиме
        \item \texttt{make run-gui} — запуск с графическим интерфейсом
        \item \texttt{make clean-all}, \texttt{make clean-cache}, \texttt{make clean-out} — очистка артефактов сборки, кэша и выходных данных
        \item \texttt{make docs} — генерация документации
        \item \texttt{make help} — вывод справки по доступным командам
    \end{itemize}
\end{itemize}

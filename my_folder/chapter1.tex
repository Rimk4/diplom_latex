В данной главе рассматриваются ключевые аспекты самоорганизующихся низкоскоростных P2P-сетей с мобильными узлами, работающими в условиях ограниченной пропускной способности радиоканала (32 бит/с – 37 кбит/с) и высокой мобильности участников (до 60 км/ч). Основное внимание уделяется проблемам децентрализованных сетей, алгоритмам маршрутизации и методам оптимизации энергопотребления. В параграфе \ref{ch1:sec1} анализируются особенности самоорганизующихся сетей, включая принципы работы P2P-сетей и специфику низкоскоростных беспроводных соединений. Параграф \ref{ch1:sec2} посвящен обзору современных алгоритмов маршрутизации и методов энергосбережения.


\section{Особенности самоорганизующихся сетей} \label{ch1:sec1}


\subsection{Децентрализованные P2P-сети: принципы функционирования} \label{ch1:sec1:subsec1} % ~ нужен, чтобы избавиться от висячего предлога (союза) в конце строки

Одноранговые (P2P) сети представляют собой распределенные системы без централизованного управления, где каждый узел может выступать как клиентом, так и сервером. Ключевые преимущества таких сетей включают:

\begin{itemize}
    \item Отказоустойчивость (отсутствие единой точки отказа)
    \item Масштабируемость (возможность динамического добавления узлов)
    \item Равноправие участников
\end{itemize}

Однако для низкоскоростных мобильных сетей характерны следующие проблемы:

\begin{equation} 
\label{eq:connection-prob}
P_{success} = e^{-\alpha d_{ij} / B}, \quad \alpha \in [0.1, 0.5]
\end{equation}
где $P_{success}$ - вероятность успешной передачи, $d_{ij}$ - расстояние между узлами, $B$ - битрейт канала.

\subsection{Проблемы низкоскоростных беспроводных сетей} \label{ch1:sec1:subsec2}

Для сетей с ограниченной пропускной способностью и мобильными узлами характерны следующие ключевые проблемы:
\begin{itemize}
    \item Нестабильность соединений из-за движения узлов (радиус действия \ge10 км)
    \item Потери данных при передаче фреймов (до 22\% в экстремальных условиях)
    \item Задержки синхронизации между узлами (\ge5 сек при 32 бит/с)
    \item Динамическое изменение топологии сети
    \item Допплер-эффект при движении узлов (±110 Гц при 862 МГц)
\end{itemize}


\section{Обзор существующих алгоритмов маршрутизации} \label{ch1:sec2} 


\subsection{Протоколы для мобильных ad-hoc сетей (MANET)} \label{ch1:sec2:subsec1}

Для самоорганизующихся сетей с мобильными узлами применяются адаптивные протоколы маршрутизации, учитывающие:
\begin{itemize}
    \item Динамику изменения позиций узлов:
    \begin{equation}
    \begin{cases} 
    x_i(t + \Delta t) = x_i(t) + v_i \cos\theta_i \Delta t \\
    y_i(t + \Delta t) = y_i(t) + v_i \sin\theta_i \Delta t 
    \end{cases}
    \end{equation}
    \item Качество связи между узлами
    \item Энергоэффективность передачи данных
\end{itemize}


\subsection{Методы оптимизации энергопотребления} \label{ch1:sec2:subsec2}

Для низкоскоростных сетей критически важны алгоритмы энергосбережения:
\begin{itemize}
    \item Адаптивный режим сна узлов:
    \begin{equation}
    T_{sleep} = 10-300 \text{ сек (адаптивный)}
    \end{equation}
    \item Приоритезация сообщений:
    \begin{equation}
    Priority = \alpha \frac{msg_{size}}{max_{size}} + (1 - \alpha) \frac{msg_{age}}{max_{age}}
    \end{equation}
    \item Оптимизация интервалов сканирования ($T_{scan} = 5-60$ сек)
\end{itemize}


\section{Выводы} \label{ch1:conclusion}

В данной главе проведен анализ особенностей самоорганизующихся низкоскоростных сетей передачи данных. Основные выводы:
\begin{itemize}
    \item Децентрализованные P2P-сети обладают высокой отказоустойчивостью, но требуют специальных алгоритмов для работы в условиях низкой пропускной способности и мобильности узлов
    \item Ключевыми проблемами являются нестабильность соединений, потери данных и задержки синхронизации
    \item Существующие алгоритмы маршрутизации и оптимизации энергопотребления требуют адаптации для работы в экстремальных условиях (32 бит/с, скорость узлов до 60 км/ч)
    \item Максимальное число узлов в сети ограничено пропускной способностью канала и составляет 31-50 узлов при идеальных условиях
\end{itemize}
